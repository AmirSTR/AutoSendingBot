# Обновление AutoSendingBot

Добавлено:
- «Мои задачи» → «Редактировать»: изменение текста, получателя или расписания.
- Выбор чисел каждого месяца (например 1 или 1 и 15).
- Выбор нескольких дней недели при создании и редактировании (например Чт и Вс).
- Расписание учитывает дату начала и показывает ближайшую подходящую отправку.
- Редактирование сохраняет номер задачи и состояние паузы.

Установка:
1. Останови бота и сохрани резервную копию AutoSendingBot/data/tasks.db.
2. Скопируй папку AutoSendingBot из архива поверх папки AutoSendingBot в репозитории,
   заменяя совпадающие файлы. Не удаляй существующую папку целиком.
   В архиве только изменённые и новые файлы; config.py, токены и база не включены.
3. Из корня репозитория установи зависимости:
   python -m pip install -r AutoSendingBot/requirements.txt
4. При желании запусти проверку:
   python -m unittest discover -s AutoSendingBot/tests -v
5. Запусти бота привычным способом. При деплое через GitHub сначала загрузи обновлённые
   файлы в репозиторий и разверни обновление на хостинге.

Примеры:
- Первого числа каждого месяца: «Расписание» → дата начала и время →
  «Числа каждого месяца» → «1» → «Готово».
- Только четверг и воскресенье: «Расписание» → дата начала и время →
  «Выбрать дни недели» → «Чт» и «Вс» → «Готово».
- Время московское. Отправок раньше даты начала не будет.
- Числа, которых нет в конкретном месяце, пропускаются (например 31 февраля).
- Для остановки отправок на время редактирования сначала поставь задачу на паузу.
- «Отмена», /cancel, /start или 5 минут бездействия отменяют несохранённые изменения.
