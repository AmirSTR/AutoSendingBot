# VK Scheduler Bot

Telegram-бот для отложенной и повторяющейся отправки сообщений в ВКонтакте.

## Структура проекта

```
vk_scheduler/
├── bot.py           # Основной код бота
├── database.py      # Работа с SQLite
├── scheduling.py    # Расчёт расписания (МСК)
├── config.py        # Настройки (токены)
├── requirements.txt # Зависимости
└── data/
    └── tasks.db     # База данных (создаётся автоматически)
```

## Установка и запуск локально

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Задать токены через переменные окружения
export TG_TOKEN="твой_токен_телеграм"
export VK_TOKEN="твой_токен_вк"
export ALLOWED_USER_ID="твой_telegram_id"  # узнать у @userinfobot

# 3. Запустить
python bot.py
```

Или вставить токены напрямую в config.py (только для локального использования).

## Деплой на Railway.app

1. Зарегистрируйся на https://railway.app
2. Создай новый проект → "Deploy from GitHub repo"
3. Загрузи файлы в GitHub репозиторий
4. В Railway → Variables добавь:
   - `TG_TOKEN` = твой токен телеграм
   - `VK_TOKEN` = твой токен ВК
   - `ALLOWED_USER_ID` = твой telegram id
5. Railway сам запустит бота

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Показать меню |
| `/add` | Добавить новое сообщение |
| `/list` | Список всех задач |
| `/delete` | Удалить задачу |
| `/pause` | Приостановить задачу |
| `/resume` | Возобновить задачу |

## Типы повторов

- **Без повтора** — отправится один раз в указанное время
- **Каждые N минут** — например каждые 60 минут
- **Каждый день** — в одно и то же время
- **Раз в неделю** — в конкретный день и время
- **Выбранные дни недели** — например только четверг и воскресенье
- **Числа каждого месяца** — например 1-е число или 1-е и 15-е

Для повторов введённая дата задаёт начало расписания: отправок раньше неё не будет.
В карточке отображается ближайшая подходящая дата, время — московское (МСК).
Если выбранного числа нет в месяце (например, 31 февраля), оно пропускается.

## Редактирование задачи

1. Открой «📋 Мои задачи» и нажми «✏️ Редактировать» в карточке.
2. Выбери «Текст», «Получателя» или «Расписание».
3. Введи новое значение. Для расписания сначала введи дату и время начала,
   затем выбери режим повтора и нужные дни кнопками, нажми «Готово».

Номер задачи и состояние паузы сохраняются. Старая задача работает до сохранения
изменений; если нужно остановить отправки на время редактирования, поставь её на паузу.
«❌ Отмена», `/cancel`, `/start` или 5 минут бездействия отменяют несохранённые изменения.
Если разовая задача уже выполнена или удалена, редактирование не создаёт её заново.

### Примеры

- **Первого числа каждого месяца в 09:00:** введи дату начала и время 09:00,
  выбери «Числа каждого месяца» → «1» → «Готово».
- **По четвергам и воскресеньям в 18:00:** введи дату начала и время 18:00,
  выбери «Выбрать дни недели» → «Чт» и «Вс» → «Готово».

## Проверка изменений

Из корня репозитория:

```bash
python -m pip install -r AutoSendingBot/requirements.txt
python -m unittest discover -s AutoSendingBot/tests -v
```

Тесты используют временную SQLite-базу и подменяют отправку сообщений.
Настоящие токены и обращения к Telegram/VK не нужны.

## peer_id для ВК

- **Личка**: ID пользователя (число из адреса страницы)
- **Беседа**: число из ссылки + 2000000000
  - Пример: `/convo/4` → peer_id = `2000000004`
- **Группа/паблик**: -ID группы
